


# Site Ano 90

A retro-styled website inspired by 90s web design, created as a web development class assignment.

## Project Structure

```
site-ano-90/
├── imagens/    # Images directory (empty)
└── index.html  # Main page
```

## Description

This is a simple single-page website with a nostalgic 90s aesthetic. The project consists of a basic HTML file with heading elements styled to evoke the early days of the World Wide Web.

## Pages

- **index.html** - Main landing page featuring:
  - Main heading: "This is a Super Home Page!"
  - Subheading: "Welcome to my HOME AND beautiful PAGE"

## Technologies

- HTML5 (no CSS or JavaScript)

## How to Run

1. Clone the repository
2. Open `index.html` in any web browser
